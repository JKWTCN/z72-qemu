# 浏览器交互台

`tools/web_console.py` 在本机启动组合模拟器，并提供实时画面与按键页面。
仅需 Python 3.12 或更新版本的标准库及已构建的 QEMU，无需安装前端依赖。
三份原厂固件通过本地路径加载，不会传给浏览器或外部服务。

## 启动

Windows 使用 Linux QEMU 构建时，在项目根目录运行以下 PowerShell 命令，
将固件路径替换为本机实际路径：

```powershell
& 'C:\Users\15056\AppData\Local\Programs\Python\Python312\python.exe' tools/web_console.py `
  --qemu .build/build/qemu-system-arm --wsl `
  --master D:\firmware\eg1840_mas_01700.bin `
  --slave D:\firmware\eg1840_sla_01700.bin `
  --controller D:\firmware\ex1840_013000.bin
```

Linux 或原生 Windows QEMU 可使用相应 Python 和 QEMU 路径，省略 `--wsl`。
随后打开 [本机交互台](http://127.0.0.1:8666)。可用 `--port` 更换端口，
或添加 `--open-browser` 自动打开浏览器。页面会在固件启动期间显示进度，
出错时显示原因并允许重启。关闭终端中的服务可使用 Ctrl+C。

## 操作

- 点击 MENU 打开菜单；键盘快捷键为 `M`。无需一直按到菜单出现。
- 方向键控制页面导航键，播放键为 `P`，确认为 `Enter`。扩展按键提供全部 24 路编号输入，
  未确认的编号不赋予具体功能名称。
- `Esc` 或“释放全部按键”释放输入；页面失焦、隐藏或离开时也发送释放。
  若浏览器直接断开，尚未收到松键请求的持续输入会在最后一次心跳后约五秒内释放。
- “持续刷新画面”只控制画面抓取，不暂停模拟器；“重启模拟器”执行冷启动。

画面由当前模拟器显示表面转换为 PNG，按键通过外部输入进入原厂扫描路径。
页面以 30 FPS 为抓取目标，上一帧请求结束后再调度下一帧，慢请求不会堆积；
隐藏页面或关闭持续刷新时停止抓取。截图像素批量写出，减少跨文件系统的小写入。
该目标表示显示表面的抓取频率；固件生成新画面的速度仍受模拟执行速度限制。
本机联调按 30 FPS 调度连续抓取 150 帧，实际交付约 29.2 帧/秒，
单次接口耗时中位数约 23.8 毫秒；这不包含浏览器绘制耗时。
性能记录见[画面传输验证](../artifacts/frame_transport_validation/report.json)。
方向键输入 5、4、7、6 分别对应原厂解码开关字的上、下、左、右逻辑位。
网页事件使用宿主时钟，固件轮询使用模拟时钟。为避免模拟器运行较慢时漏掉
短点击，服务按硬件计数器保证每个按下及两次点击间的释放电平至少持续
100 毫秒模拟时间；连续点击保留各自边沿，取消操作则立即释放并清空队列。
这是输入采样窗口，不会等待菜单出现才释放，也不调用固件菜单入口。
状态查询读取应用管理器，不暂停各核。每个服务实例控制一个模拟器，
建议仅打开一个操作页面，避免不同页面同时发送按键。

## 当前边界

本地联调已通过 HTTP 长按 MENU 打开原厂菜单、释放后保持菜单，以及向下
输入使高亮移动一项；画面为 720×480 PNG。浏览器布局和实际点击尚未完成
自动化验证，无固件检查覆盖接口、图像编码、断线释放和重启互斥。
本次记录见[交互台验证](../artifacts/browser_console_validation/report.json)。
后续短按验证确认：100 毫秒模拟时间的按下后先释放，菜单仍能打开。
短点击的宿主时间与实际输入时长分别记录，见
[短按验证](../artifacts/menu_short_press_validation/report.json)。
较晚一次 HTTP 短点击没有打开菜单，同次原厂状态列表含 `0x3f`。
页面现区分这种状态拦截与输入是否就绪，提示运行异常；该运行问题仍待解决，
不能把短点击修复等同于所有启动阶段都能正常打开菜单。

启动沿用实验电池对端、内部参数、正文为零的资源头及一次初始同步输入。
这些输入不代表机身校准数据或真实传感器帧。按菜单的启动时机可能影响
固件响应；菜单项语义、所有按键功能及完整机身行为仍待验证。
页面报告的前台应用与实际画面应结合判断，不能将服务运行等同于完整启动。

运行目录由服务创建在 `.local/web-console-*`，重启或正常退出时清理自己创建的
临时文件。服务仅监听 `127.0.0.1`，不提供远程访问或固件上传接口。

无固件检查：

```sh
python -B -m unittest checks.test_web_console -v
node --check web/console.js
```
