# Z7 II 失败认证法读取校验材料

适用于 **WSL、Z7 II、C 1.70**。原理:把官方更新包头部 20 字节期望摘要翻一位,
解码正文保持逐字节一致。菜单选"是"后,整包认证照常执行(材料进入
`0xB2B422C8` 校验上下文并完成变换),随后的 SHA-1 对比必然失败——固件走
已被分析的失败分支,**不进入更新准备、不编程**;而上下文在失败比对后
保留变换后的材料(两种比对结果均保留,见
[服务分析](../research/z7ii/ptp_service.md)),清空只发生在下一次认证
开始或重启。菜单的候选收集/版本读取/确认页均不触碰认证链(见
[确认页分析](../research/z7ii/menu_confirmation.md)),因此坏摘要文件
照常到达确认页。

2026-10-25:该流程已在实机完成验证,原包摘要比对通过。材料值刻意不进入
本仓库(代码、文档、报告均无密钥字节);运行产出只落在本地
`verified-material.json`,按注记自行保管。

## 1. 制备坏摘要文件(不连接相机)

在仓库根目录的虚拟环境中执行;`--master` 为 C 1.70 master,`--original`
为官方原包。

```bash
cd tools
python ./ptp_failed_auth_probe.py --prepare \
    --master ../../../Temporary/2610/07/Z_72/eg1840_mas_01700.bin \
    --original ../../../Temporary/2610/24/z72/Z7_2_0170.bin \
    --output ../.local/Z7_2_0170_bad_digest.bin
```

输出确认 `body_identical: true`、`container_crcs_valid: true`、仅偏移 0
一处差异。把输出文件拷到 SD 卡根目录并**重命名为官方更新文件名**
(如 `Z7_2_0170.bin`);确认卡上没有另一份固件文件。电池充足。

## 2. 相机操作

1. 菜单 → 固件版本 → 进入确认页(版本显示正常,版本读取不需要校验材料)。
2. 选择**执行/是**。等待数秒(整包解码与 SHA-1)。
3. 预期出现更新失败/文件无效提示——这是本流程的成功路径;不会开始写入。
   若意外出现更新进度(不应发生),不要断电,等同正常同版本重刷。
4. 退出菜单,**保持开机**,连接 USB 到 WSL(`lsusb` 应见 `04b0:044b`)。
   不要再次运行更新检查;不要关机或开电池仓。

菜单代码不引用校验上下文(全镜像仅认证链三个函数可触达);退出菜单只为
让 PTP 会话机制离开模态页面状态。USB 插入/拔出经实机验证不重启相机
(RAM 状态跨重插存活)。

## 3. 读取与验证

```bash
python ./ptp_failed_auth_probe.py --execute \
    --master ../../../Temporary/2610/07/Z_72/eg1840_mas_01700.bin \
    --original ../../../Temporary/2610/24/z72/Z7_2_0170.bin \
    --used ../.local/Z7_2_0170_bad_digest.bin \
    --destination ../.local/failed-auth-1
```

结果判读(`report.json`):

| 字段                                                 | 含义                            |
| ---------------------------------------------------- | ------------------------------- |
| `phase: "transformed"`                             | 上下文处于变换后状态(材料在场)  |
| `expected_matches_used_package: true`              | 认证处理的确是坏摘要文件        |
| `context_binding_valid: true`                      | 回调/机型/长度/期望摘要全部绑定 |
| `material_recovered` / `package_digest_verified` | 材料对原包 SHA-1 头的复现结果   |

全真时,`../.local/failed-auth-1/verified-material.json` 含材料字节
(仅本地,勿提交/外发);`context.bin` 为原始 52 字节快照。

## 4. 收尾

读取完成后可正常关机;**删除 SD 卡上的坏摘要文件**。如需进一步确认,
可用同一材料对其他历史官方包逐一复验 SHA-1 头(同一机型固件线共钥)。

## 边界

- 本工具不发任何更新类操作码,不进行菜单输入;相机侧操作由使用者完成。
- 失败分支先于更新准备(执行阶段对照已验证);最坏情况为正常同版本重刷。
- 地址与常量仅适用 Z7 II C 1.70;跨版本不可套用。
