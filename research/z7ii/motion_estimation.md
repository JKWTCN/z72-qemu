# NikonMotionDetector Ver6.0 2013.09.19

本报告以 Z7 II v1.70 固件中的原始字节、指令、数据访问和局部调用关系为依据。所有地址均为拆分成员内文件偏移，不是运行时地址；未验证真实拍摄行为。

## 身份与结论

版本字符串位置：master `0x73F554`、slave `0xEEA10`、Z30 `0x56D0C8`。slave `0xEE618` 的 ADR/BX 返回 `0xEEA10`，初始化函数 `0xEE61C` 调用这个 getter 并存入对象首字段，因此字符串可以明确关联到后述算法对象。日期是算法库的版本标识，不能解释为相机固件发布日期。

已确认的实际调用路径，是两幅图像之间的多尺度整体运动估计：先估计旋转和平移，再进行六参数仿射拟合，最后输出四角的映射坐标、亚像素部分和状态。其梯度、固定参考矩阵、残差累积和迭代更新结构符合 Lucas–Kanade 类直接图像配准；这是算法结构判断，未发现原始算法名或源代码。

## 调用流程与证据

以下均以 slave 为例。

| 偏移 | 已核对的行为 |
|---|---|
| `0xA1552` | 实际调用者；初始化局部算法对象，获取工作缓冲，循环处理由尺度索引选出的两组图像，再调用仿射阶段 |
| `0xEE608` | 设置尺寸/容量信息；返回工作空间大小 `0x2BF20`，内部点容量常量为 5000 |
| `0xEE61C` | 初始化对象，检查工作空间，设置默认参数，存入版本 getter 的结果 |
| `0xEE67E` | 配置图像宽高；反复将尺寸减半，直到像素积小于 10000，计算尺度计数；清零三参数和两组六参数结果 |
| `0xEF010` | 三参数阶段入口：记录宽高/步长，准备参考梯度，求解参考矩阵，迭代对齐另一幅图，检查旋转参数范围，更新下一尺度的坐标和位移尺度 |
| `0xEECD8` | 在规则分区中比较候选像素的梯度平方和，保留较强梯度位置；每点保存参考亮度、坐标和三个导数项，累积对称 3×3 矩阵的六个独立项 |
| `0xEE956` | 对上述矩阵进行整数求解/构造求解系数，检查零分母及退化条件 |
| `0xEE71E` | 对每个参考点在另一幅图上采样，计算亮度残差，累积残差乘导数，更新三个参数；最多 16 次；三个参数增量均严格在 (-10,10) 内时提前结束 |
| `0xF2EC2` | 三参数坐标变换、范围检查、四邻点双线性插值 |
| `0xF2C18` | 六参数阶段入口；用三参数结果初始化仿射参数，调用参考点准备、矩阵求解和迭代细化，检查拟合质量及参数范围 |
| `0xF279C` / `0xF2748` | 每个分区比较四个候选位置的梯度平方和，选两个位置，保存导数项；累积对称 6×6 矩阵的 21 个独立项 |
| `0xEF90E` | 六参数矩阵求解相关大函数 |
| `0xEF320` | 累积亮度残差及六个导数方向的更新量，迭代拟合，记录误差统计 |
| `0xEF246` | 六参数坐标变换、范围检查、双线性插值 |
| `0xF2D72` | 以当前或另一组保存的六参数计算坐标；返回整数坐标、亚像素部分和是否处于可采样范围 |

调用者 `0xA15B8–0xA15DE` 按递减尺度索引多次调用 `0xEF010`；`0xA15F8` 随后调用 `0xF2C18`。`0xA1620/0xA1632/0xA1644/0xA1656` 分别对 (0,0)、(W,0)、(0,H)、(W,H) 调用 `0xF2D72`，将四角映射结果写入输出结构。这是实际调用证据，不只是未使用的库字符串。

## 数学解释

忽略整数截断、坐标中心转换和尺度转换，三参数采样器使用：

```text
x' = x + (p1 - p0*y) / 32768
y' = y + (p2 + p0*x) / 32768
```

`p0` 对应小角度旋转项，`p1/p2` 对应平移项。它是小角度线性化模型，不是直接计算 sin/cos 的完整旋转。

六参数采样器使用：

```text
x' = x + (q0*x + q2*y + q4) / 32768
y' = y + (q1*x + q3*y + q5) / 32768
```

因此可以表达一般二维仿射变化，包括平移、旋转、缩放、剪切。Q15 参数与 Q8 采样坐标间的转换，可由先将原坐标左移 8 位、将参数线性组合算术右移 7 位验证。采样器再对四个邻点按 256 为分母的权重做双线性插值。

概念上的目标是使参考点亮度和变换后的另一图像亮度尽量一致。每轮由亮度残差和参考梯度推导参数修正量，并使用 64 位整数累积及带符号除法。`0x147CCC` 已按 ARM 核对为带符号 64 位除法 helper。

## 界限

已经确认图像对齐算法和实际调用，尚未追到顶层拍摄模式、所有图像缓冲的来源及最终消费者。不能据此断言它专门用于视频电子防抖、HDR、降噪合成、AF，或主从处理器如何逐帧分工。master/slave 都带有该字符串不证明两者同时执行。

算法按图像亮度一致性估计整体变换；低纹理、模糊、大幅局部运动或亮度变化可能影响其结果，这是模型性质的推断。代码确有越界、矩阵退化、误差和变换参数范围检查，具体错误码名称尚未恢复。

指令中的分支和访问关系用于区分代码、字面量池与版本字符串；仅凭连续字节解码不能确定函数边界。
