# 串行总线与控制器等待边界

原厂主处理器的通道表位于 `0xB1802090`，共 11 项，每项 88 字节。
寄存器基址从 `0x2C0A0000` 起，每通道间隔 `0x100`。发送中断为
`193 + 2 × 通道号`，接收中断为 `192 + 2 × 通道号`。
初始化函数 `0x10242FDA` 读取偏移 `0x48` 的容量并保存在通道对象中。

收发驱动的寄存器用途如下。地址均为通道内偏移。

| 偏移 | 原厂用途 | 当前模型 |
|---|---|---|
| `0x00` | 写入发送半字 | 有界发送 FIFO |
| `0x04` | 读取接收半字 | 有界接收 FIFO |
| `0x10` | 字宽及格式 | 配置存储，接收值遵守字宽 |
| `0x14` | 位 4 满、位 5 接收空、位 2 发送空闲 | 动态状态 |
| `0x20` | 中断使能 | 发送与接收线路分别投递 |
| `0x24` | 中断原因 | 完成原因 |
| `0x28` | 应答原因 | 写一清除 |
| `0x3C` | 位 0 运行使能 | 禁用时取消传输 |
| `0x48` | FIFO 容量 | 实验值 64 |
| `0x4C` | 阈值 | 低字节控制接收通知阈值 |
| `0x60` | 初始化复位写入 | 清除队列与完成状态 |

模型在虚拟时间 100 微秒后完成提交的半字，未连接设备时采样高电平。
容量与时序均为实验选择，不能作为实际硬件参数。控制器应答、面板
命令、总线电气行为及其他串行模式尚未实现。模型拒绝空 FIFO 读取、
溢出写入、未启用发送及不支持的访问宽度。

原厂发送任务在 `0x1020B846` 检查控制器就绪输入。引脚描述符
`0xB180376C` 将它定位到 `0x04282014` 位 9；接收就绪为同一寄存器
位 10，发送应答为 `0x04282018` 位 15。未连接控制器时，这些输入
保持低电平。原厂已排队的首帧为 256 字节，通道 1、路由 1、有效载荷
长度 28；尾部标志和加和校验通过。探针仅记录帧结构与校验结果。

附加控制器固件的复位向量指向 `0x080002B5`，初始栈为 `0x20000C08`。
复位代码将向量复制到 `0x20000000..0x200001C4` 并设置向量基址，
运行时内存上界为 `0x20040000`。原厂启动还配置浮点相关控制寄存器。
这些结构支持继续分析控制器执行与通信，完整外设行为尚未确认。
[独立控制器环境](controller_core.md) 已验证复位与初始化，
[组合机器](controller_embedded.md) 也已同时执行三份原厂映像。
实验[发送链路](controller_link.md) 已把原厂首帧交给控制器并通过
原厂校验，完整反向响应及菜单显示仍未验证。

`tests/test_spi.py` 用合成指令检查主从两侧的队列边界、字宽、中断线路、
异步完成、取消与复位。`tools/spi_boot_probe.py` 从原厂复位入口执行，
检查原厂驱动读取容量、配置 16 位字宽、排队有效帧并等待控制器输入。
两者均不证明完整启动或菜单显示。
